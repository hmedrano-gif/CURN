Por qué un modelo y no 8 tablas sueltas

💡 En palabras simples: Un modelo en estrella tiene una tabla central con lo que se mide (viajes, dinero) y tablas alrededor para filtrar (zonas, fechas). Así Power BI calcula rápido y sin errores.

En BigQuery se resume el mes en una tabla de hechos (una fila por fecha, hora, empresa y zona: unas 357.000 filas en vez de 20 millones) y dos dimensiones (zonas y aeropuertos). Power BI importa solo eso, en segundos, y con medidas DAX responde las 8 preguntas, con filtros por empresa, día y borough. Es el diseño en estrella que usan las empresas.

Paso 1 · Las tablas del dashboard en BigQuery

1.1 Ejecutar el script de las tablas

💡 En palabras simples: Un script es un grupo de consultas que se ejecutan juntas. Este crea las 3 tablas resumidas que usará Power BI.

En BigQuery abre una consulta nueva, pega todo el script y pulsa Ejecutar (unos 25 segundos). Crea 3 tablas.

-- Taller 2B - Tablas que Power BI importa desde BigQuery (cambia 2025_06 por tu mes).
-- 1) hechos_viajes: una fila por fecha, hora, empresa y zona de recogida, con las sumas que necesitan las 8 preguntas.
--    Del mes completo (unos 20 millones de viajes) quedan unas 300.000 filas: Power BI las importa en segundos.
CREATE OR REPLACE TABLE tpd.hechos_viajes AS
SELECT
  DATE(pickup_datetime) AS fecha,
  ['1-lunes','2-martes','3-miercoles','4-jueves','5-viernes','6-sabado','7-domingo'][OFFSET(CAST(FORMAT_DATE('%u', DATE(pickup_datetime)) AS INT64) - 1)] AS dia,
  EXTRACT(HOUR FROM pickup_datetime) AS hora,
  CASE hvfhs_license_num WHEN 'HV0003' THEN 'Uber' WHEN 'HV0005' THEN 'Lyft' ELSE hvfhs_license_num END AS empresa,
  PULocationID AS zona_id,
  COUNT(*) AS viajes,
  SUM(CAST(base_passenger_fare AS NUMERIC)) AS tarifa_base_usd,
  SUM(CAST(driver_pay AS NUMERIC)) AS pago_conductor_usd,
  COUNTIF(tips > 0) AS viajes_con_propina,
  SUM(CAST(tips AS NUMERIC)) AS propinas_usd,
  COUNTIF(cbd_congestion_fee > 0) AS viajes_con_cargo,
  SUM(CAST(cbd_congestion_fee AS NUMERIC)) AS cargo_congestion_usd,
  COUNTIF(m > 0) AS viajes_con_millas,
  SUM(IF(m > 0, CAST(driver_pay AS NUMERIC), 0)) AS pago_con_millas_usd,
  SUM(IF(m > 0, m, 0)) / 100 AS millas,
  COUNTIF(m > 0 AND trip_time > 0) AS viajes_velocidad,
  SUM(IF(m > 0 AND trip_time > 0, m, 0)) / 100 AS millas_velocidad,
  SUM(IF(m > 0 AND trip_time > 0, trip_time, 0)) AS segundos_velocidad
FROM (SELECT *, ROUND(CAST(trip_miles * 100 AS BIGNUMERIC), 0, 'ROUND_HALF_EVEN') AS m FROM tpd.viajes_2025_06)
GROUP BY fecha, dia, hora, empresa, zona_id;

-- 2) aeropuertos: viajes desde y hacia Newark, JFK y LaGuardia (pregunta 4), por empresa.
CREATE OR REPLACE TABLE tpd.aeropuertos AS
WITH aero AS (SELECT * FROM UNNEST([STRUCT(1 AS id, 'Newark' AS aeropuerto), (132, 'JFK'), (138, 'LaGuardia')])),
partes AS (
  SELECT a.aeropuerto, 'desde' AS sentido, v.* FROM tpd.viajes_2025_06 v JOIN aero a ON v.PULocationID = a.id
  UNION ALL
  SELECT a.aeropuerto, 'hacia', v.* FROM tpd.viajes_2025_06 v JOIN aero a ON v.DOLocationID = a.id)
SELECT aeropuerto, sentido,
  CASE hvfhs_license_num WHEN 'HV0003' THEN 'Uber' WHEN 'HV0005' THEN 'Lyft' ELSE hvfhs_license_num END AS empresa,
  COUNT(*) AS viajes,
  SUM(CAST(base_passenger_fare AS NUMERIC)) AS tarifa_base_usd,
  SUM(CAST(airport_fee AS NUMERIC)) AS cargo_aeropuerto_usd,
  SUM(CAST(driver_pay AS NUMERIC)) AS pago_conductor_usd
FROM partes GROUP BY aeropuerto, sentido, empresa;

-- 3) dim_zonas: nombre y borough de cada zona. La columna zona_id se llama igual que en hechos_viajes,
--    así Power BI crea solo la relación entre las dos tablas.
CREATE OR REPLACE TABLE tpd.dim_zonas AS
SELECT LocationID AS zona_id, Zone AS zona, IF(Borough = 'N/A', 'Fuera de NYC', Borough) AS borough
FROM tpd.zonas;
Debe salir: «Todos los resultados» con 3 declaraciones en verde: hechos_viajes, aeropuertos y dim_zonas.

Paso 3 · Las medidas DAX

Cómo se crea una medida

💡 En palabras simples: Una medida DAX es una fórmula guardada que calcula un número (por ejemplo, el total de viajes). Se recalcula sola cada vez que filtras.

En el panel Datos clic derecho sobre hechos_viajes → Nueva medida. Borra lo que trae la barra de fórmulas, pega la medida y pulsa Enter. Con la medida seleccionada, en la cinta Herramientas de medición elige el formato. Las tres últimas se crean sobre la tabla aeropuertos.

Por qué: una medida calcula el resultado en el contexto de cada visual: la misma «% Plataforma» da el total en una tarjeta y el valor de cada hora en un gráfico. Por eso los promedios se calculan como suma ÷ suma, nunca promediando promedios.
Si falla: «ya existe una columna con ese nombre»: una medida no puede llamarse igual que una columna; por eso se llama «Total viajes» y no «viajes».

Total viajes

Total viajes = SUM(hechos_viajes[viajes])

Formato: Número entero, separador de miles.

Tarifa base

Tarifa base = SUM(hechos_viajes[tarifa_base_usd])

Formato: Moneda.

Plataforma

Plataforma = [Tarifa base] - SUM(hechos_viajes[pago_conductor_usd])

Formato: Moneda.

% Plataforma

% Plataforma = DIVIDE([Plataforma], [Tarifa base])

Formato: Porcentaje, 2 decimales.

Tarifa promedio

Tarifa promedio = DIVIDE([Tarifa base], [Total viajes])

Formato: Moneda, 2 decimales.

Plataforma por viaje

Plataforma por viaje = DIVIDE([Plataforma], [Total viajes])

Formato: Moneda, 2 decimales.

% con propina

% con propina = DIVIDE(SUM(hechos_viajes[viajes_con_propina]), [Total viajes])

Formato: Porcentaje.

Propina promedio

Propina promedio = DIVIDE(SUM(hechos_viajes[propinas_usd]), SUM(hechos_viajes[viajes_con_propina]))

Formato: Moneda, 2 decimales.

Pago por milla

Pago por milla = DIVIDE(SUM(hechos_viajes[pago_con_millas_usd]), SUM(hechos_viajes[millas]))

Formato: Moneda, 2 decimales.

Velocidad mph

Velocidad mph = DIVIDE(SUM(hechos_viajes[millas_velocidad]), SUM(hechos_viajes[segundos_velocidad]) / 3600)

Formato: Decimal, 2 decimales.

Recaudo congestión

Recaudo congestión = SUM(hechos_viajes[cargo_congestion_usd])

Formato: Moneda.

% con cargo congestión

% con cargo congestión = DIVIDE(SUM(hechos_viajes[viajes_con_cargo]), [Total viajes])

Formato: Porcentaje.

Viajes aeropuerto

Viajes aeropuerto = SUM(aeropuertos[viajes])

Formato: Número entero.

Tarifa promedio aeropuerto

Tarifa promedio aeropuerto = DIVIDE(SUM(aeropuertos[tarifa_base_usd]), [Viajes aeropuerto])

Formato: Moneda, 2 decimales.

Plataforma aeropuerto

Plataforma aeropuerto = SUM(aeropuertos[tarifa_base_usd]) - SUM(aeropuertos[pago_conductor_usd])

Formato: Moneda.

Comprobar con la clave

EVALUATE SUMMARIZECOLUMNS(hechos_viajes[hora], "viajes", [Total viajes], "pct", [% Plataforma])

Pégala en la Vista de consultas DAX y ejecútala: cada hora debe coincidir con la pregunta 1 de la clave de tu mes.

Paso 4 · Las tres páginas del dashboard

💡 En palabras simples: Un visual es un gráfico. Se elige el tipo (barras, líneas, tarjeta) y se le dicen qué campos van en cada eje.

Clic en un espacio vacío del lienzo → clic en el icono del visual en Compilar → en cada casilla (Eje X, Eje Y, Leyenda) pulsa Agregar datos y escribe el nombre del campo. Para el título: pestaña Formato del visual → General → Título. Arriba de cada página pon un Cuadro de texto con la pregunta de la página y la fuente.
